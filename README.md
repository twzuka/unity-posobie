# Пособие по Unity

Основы Unity для начинающих: от первого проекта и знакомства с редактором до создания уровней, эффектов и программирования на C#.

**Открыть пособие:** https://twzuka.github.io/unity-shpora/

В каждой главе есть объяснения с примерами, пошаговые инструкции и наглядные схемы. В приложениях собраны горячие клавиши, решения частых проблем и словарик терминов.

Пособие пополняется по мере прохождения новых тем.
